# 📍 PostOffice Finder

An Android application built with **Kotlin** that helps users search and view details of post offices across India.

---

## ✨ Features
- Search post offices by **PIN code** or **area name**.
- Display details such as **branch type, name, and address**.
- Simple, lightweight UI using XML layouts.
- Fast and efficient data handling.

---

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI:** XML Layouts + Android Views
- **Architecture:** MVVM (ViewModel + LiveData/StateFlow)
- **Data Source:** India Post API / REST API integration
